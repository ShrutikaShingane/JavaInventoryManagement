
# Inventory Management System

## Description
A console-based Java application to manage inventory items using Map, Optional, and custom exceptions.

## Features
- Add inventory items.
- Search items by ID.
- Decrease item stock.
- Display all items.
- Prevent duplicate item IDs.
- Handle insufficient stock using a custom exception.

## Technologies Used
- Java 11
- Eclipse IDE
- Apache Maven

## Concepts Used
- Map and HashMap
- Optional
- Exception handling
- Custom exceptions
- Object-oriented programming

## How to Run
1. Import the project into Eclipse as an Existing Maven Project.
2. Open Main.java.
3. Right-click and select Run As → Java Application.
4. Select an operation from the console menu.

## Build
Run `mvn clean package` to build the project.
